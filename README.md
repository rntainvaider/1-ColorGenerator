3. Шрифты
Для такого интерфейса я рекомендую использовать два шрифта.
Manrope
Заголовки

Color Generator
Современный геометрический шрифт, хорошо подходит для крупных заголовков.

Рекомендуемый вес: 700–800.


Inter
Основной текст

Generate new color
Читаемый и универсальный шрифт для кнопок, описаний и HEX-кодов.

Рекомендуемый вес: 400–600.


Оба шрифта доступны бесплатно на Google Fonts.

5. Что использовать в проекте
Я бы зафиксировал следующие правила:
- Manrope — заголовки.
- Inter — весь остальной текст.
- Фиолетово-синий градиент — основные кнопки.
- Glassmorphism — карточки и декоративные элементы.
- CSS-переменные — хранение цветов обеих тем.
Последний пункт особенно важен: рекомендую изучить CSS Custom Properties (--primary-color, --background-color и т. д.). Они позволят переключать темы без переписывания всех стилей.
